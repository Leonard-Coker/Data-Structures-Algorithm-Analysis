# Stacks Implementation — Data Structures and Algorithms

## Project purpose
This Python project evaluates arithmetic expressions from a text file using two stacks: an operand stack and an operator stack. It supports `+`, `-`, `*`, `/`, parentheses, decimal values, and unary plus/minus in common expressions. It does **not** use Python's `eval()`.

## Requirements
- Python 3.9 or later
- No third-party packages

## Files
- `main.py` — command-line entry point
- `stack.py` — Stack class (`push`, `pop`, `peek`, `is_empty`, `size`)
- `tokenizer.py` — turns expression text into tokens
- `expression_evaluator.py` — stack-based calculation and precedence
- `file_handler.py` — reads input, preserves separator/blank lines, writes output
- `input.txt` — sample input
- `output.txt` — sample output (generated by running the program)
- `tests/` — test cases and a standard-library unit test suite
- `docs/REPORT_GUIDE.md` — report-writing guide

## Run in VS Code
1. Open the `Stacks_Implementation_Assignment` folder in VS Code.
2. Ensure Python is installed and selected in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:
   ```bash
   python main.py
   ```
   On some Windows setups, use `py main.py`.
5. The program reads `input.txt` and writes results to `output.txt`.

You may specify other files:
```bash
python main.py --input tests/inputs/mixed_expressions.txt --output output.txt
```

## Input format
Put one arithmetic expression on each line. Lines consisting of three or more hyphens, such as `------`, are treated as separators and copied to the output. Blank lines are preserved.

## Error handling
Malformed expressions and division by zero are written as `ERROR: ...` lines. The program reports error line numbers in the terminal and returns a non-zero exit status if any expression line fails. This error format is a design decision because the assignment does not specify a required error-output format.

## Test
Run:
```bash
python -m unittest discover -s tests -v
```

## Algorithm overview
1. Tokenize the expression.
2. Push numbers to the operand stack.
3. Push operators to the operator stack.
4. Before pushing an operator, apply operators of equal or higher precedence, stopping at an opening parenthesis.
5. On a closing parenthesis, apply operators until the matching opening parenthesis is found.
6. Apply any remaining operators and return the single result.

## Limitations and notes
- The implementation is intended for arithmetic expressions using the operators listed above.
- It uses ordinary Python numeric types; division may produce floating-point results.
- Check the test suite and inspect the generated output before submitting.
